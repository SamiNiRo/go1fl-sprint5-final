# Модуль фитнес-трекера

Консольное приложение для обработки данных о физической активности, реализованное на языке Go.  
  
Программа обрабатывает информацию о количестве пройденных шагов, продолжительности активности и типе тренировки (ходьба или бег). На основе этих данных, а также роста и веса пользователя рассчитываются пройденное расстояние, средняя скорость и количество потраченных калорий.  
  
Учебный проект, выполненный в рамках прохождения курса «Основы разработки на языке Go».

## Установка и запуск

1. Проверьте наличие Go на компьютере.
2. Скачайте проект.
3. Перейдите в папку проекта и запустите программу:

```
go run ./cmd/tracker
```
